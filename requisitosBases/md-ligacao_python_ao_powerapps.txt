## 1. REGRAS DE NEGÓCIO E SEQUENCIAMENTO (PYTHON)
**Arquivo de Referência:** `planner_logic.py` (Lógica de dataframes)
*   **Problema Corrigido:** Itens críticos (Status 3) estavam roubando a numeração da produção normal e quebrando a "escadinha" de horários no app.
*   **Regra de Sequência Adotada:** 
    *   **Produção Normal (`STATUS == 2`):** Recebem numeração sequencial (`1, 2, 3...`).
    *   **Itens Críticos/Extras (`STATUS == 3`):** Recebem `sequencia = 0`.
    *   **Cabeçalhos de Turno (Ex: "1º TURNO"):** Recebem `sequencia = 0`.
*   **Aplicação:** Uso de máscaras booleanas no `groupby` do Pandas para que a iteração de sequência afete exclusivamente os itens de Status 2.

## 2. BACKEND: INTEGRAÇÃO GRAPH API E BATCHING
**Arquivo de Referência:** `sharepoint_utils.py`
*   **Problema Corrigido:** Timeout, limite de requisições (Erro 429 - Throttling) e expiração de token ao enviar mais de 170 itens. O envio demorava +5 minutos.
*   **Soluções Aplicadas:**
    1.  **Globalização do MSAL:** O `ConfidentialClientApplication` foi instanciado globalmente para gerenciar o cache do token de forma nativa.
    2.  **JSON Batching (Envio Assíncrono/Lotes):** Uso do endpoint `/$batch` para enviar 20 itens por vez em uma única requisição HTTP.
    3.  **Tratamento de Throttling:** Pausa estratégica (`time.sleep`) se a API da Microsoft retornar erro 429.

### Código Python Atualizado (`send_data_to_sharepoint_graph`):
```python
import requests
import pandas as pd
import time
from datetime import datetime, date
from msal import ConfidentialClientApplication
import config

# Configurações API e MSAL Global (Cache nativo)
GRAPH_SCOPE = ["[https://graph.microsoft.com/.default](https://graph.microsoft.com/.default)"]
AUTHORITY_URL = f"[https://login.microsoftonline.com/](https://login.microsoftonline.com/){config.TENANT_ID}"

msal_app = ConfidentialClientApplication(
    client_id=config.CLIENT_ID,
    authority=AUTHORITY_URL,
    client_credential=config.CLIENT_SECRET
)

def get_graph_token():
    token_response = msal_app.acquire_token_for_client(scopes=GRAPH_SCOPE)
    if "access_token" in token_response:
        return token_response["access_token"]
    raise Exception(f"Falha ao obter token: {token_response.get('error_description')}")

def send_data_to_sharepoint_graph(df: pd.DataFrame, list_name: str):
    """Envia um DataFrame para o SharePoint usando Batch Requests (Lotes de 20)."""
    try:
        token = get_graph_token()
        site_id = get_site_id(token) # Pressupõe função get_site_id existente
        list_id = get_list_id(token, site_id, list_name) # Pressupõe função get_list_id
        
        batch_endpoint = "[https://graph.microsoft.com/v1.0/$batch](https://graph.microsoft.com/v1.0/$batch)"
        headers = {"Authorization": f"Bearer {token}", "Content-Type": "application/json"}
        batch_size = 20 
        all_items = df.to_dict('records')
        
        for i in range(0, len(all_items), batch_size):
            batch_chunk = all_items[i:i + batch_size]
            batch_payload = {"requests": []}
            
            for j, row in enumerate(batch_chunk):
                item_properties = {}
                for df_col, sp_col in config.DF_TO_SP_MAP.items():
                    if df_col in row and pd.notna(row[df_col]):
                        value = row[df_col]
                        if isinstance(value, (datetime, pd.Timestamp, date)):
                            item_properties[sp_col] = value.isoformat()
                        else:
                            item_properties[sp_col] = str(value)
                
                request_id = str(i + j + 1)
                batch_payload["requests"].append({
                    "id": request_id,
                    "method": "POST",
                    "url": f"/sites/{site_id}/lists/{list_id}/items",
                    "body": {"fields": item_properties},
                    "headers": {"Content-Type": "application/json"}
                })
            
            response = requests.post(batch_endpoint, headers=headers, json=batch_payload)
            
            # Tratamento de Throttling (Erro 429)
            if response.status_code == 429:
                 time.sleep(10)
                 response = requests.post(batch_endpoint, headers=headers, json=batch_payload)
                 
            response.raise_for_status()
            
    except Exception as e:
        print(f"Erro Crítico ao enviar dados via Batch Graph: {e}")
